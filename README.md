# The Veilborn

*A Minecraft Java Edition expansion about a dimension where reality does not always obey its own rules.*

The Veilborn takes players beyond reality into a mysterious dimension of ethereal islands, silver oceans, ancient ruins, and shifting gravity. Explore the remains of a vanished civilization, face powerful bosses, and uncover a truth hidden beyond the veil.

> **Status:** Early planning and development. Features described below are goals, not promises of what is already implemented.

## Vision

The Veilborn is designed around a contrast: the dimension should feel breathtaking to discover, but increasingly unsettling the farther you travel. Its landscapes, structures, creatures, and mysteries should feel connected to a world with unfamiliar rules.

## Planned features

- **A new dimension** featuring ethereal floating islands and silver oceans.
- **Shifting gravity** with local zones, player abilities, and rare large-scale events.
- **Ancient structures** that hint at a vanished civilization.
- **Exploration and progression** built around discovering how the dimension works.
- **Distinct creatures and bosses**, including encounters that subvert expectations.
- **A deeper mystery** whose full explanation will be revealed gradually.

These ideas are still being designed and may change as development progresses.

## Development approach

The project will be developed in stages:

1. Document the dimension, atmosphere, and core gameplay ideas.
2. Choose a Minecraft version and compatible mod loader.
3. Establish the project structure and basic mod entry point.
4. Implement and validate features incrementally.
5. Test in Minecraft and refine based on results.

Until in-game testing is available, documentation, code review, and automated checks will be used where practical. They do not replace testing in Minecraft.
